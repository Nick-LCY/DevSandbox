## 四、测试与取证要点

- **后端**（461 passed）：
  - `emulator` 单测 **10 条**：**ctype 矩阵**（逐字段宽度与取值，钉住「显式 ctype」红线）、**快照往返幂等**（导出 → 重放 → 再导出逐字节一致）、**kitty 恢复序列**（键盘协议相关序列的恢复口径）。
  - `sessions` 改写 + 新增：**迟到 `attach` 补发快照**、**切点不重不漏**（快照与实时流的边界既不重复也不丢字节）、**并发附着不重复**。
- **前端**（1041 passed）：
  - 常驻 **15 条新用例**（含「来回切标签挂载次数恒为 1」、只挂载已访问会话、关闭会话后槽位消失、`focusRequestId` 一次请求只回填一次）；
  - **快照分片一致性**（缺片 / 序号重复 / 非法 base64 一律丢弃）；
  - **`reset` 后 OSC handler 仍存活**（承重用例：pwd 通道不能因恢复流的 reset 而断掉）。
- **e2e**（`17-terminal-snapshot.spec.ts` 四条，全过）：取证动作**刻意用 `page.reload()`**——实例常驻之后「切标签」只是 `display:none`，快照路径一次都执行不到；reload 把旧 xterm 连同 DOM 一起销毁、页面按路由重新附着，是最强的重挂载。
- **旧客户端 / 旧后端兼容**：旧前端（不发 `attach`）走 1 秒超时回退环形缓冲；新前端对旧后端的「无法识别的终端指令」错误帧**静默豁免**并补发 `resize`。混搭矩阵以 `apps/web/backend/API.md` 12.3 为准。

## 五、已知限制与留白

1. **快照只恢复活动屏**：pi 全屏（备用屏）期间主屏里的早期输出**不回放**——这是「不再重放历史」的必然代价；屏幕上看得见的内容一定在。
2. **回滚深度两侧不同**：服务端模拟器 **1000 行** vs 前端 xterm **5000 行**，长会话重挂载后可回滚历史降到 ≤1000 行。
3. **键盘协议标志不可恢复**：kitty 键盘协议等协商标志不在恢复流里（前端 xterm.js 5.5.0 不支持）⇒ 待办 ③ 仍需前端自定义映射，本轮不因快照而变得可行。
4. **Obsidian 往返后「已访问集合」清零**：切 Obsidian tab 仍是分屏整体卸载（既有约定 + e2e 断言不动），组件重建后已访问集合从空开始，各会话再点开时**重走一次快照**。
5. **隐藏会话持有 WebSocket**：常驻槽位各持一条连接（单沙箱会话上限 5 条），连接数有界、不随标签数量增长。
6. **单次 e2e 75/75 受宿主内存制约**：11 GiB 用满 + swap 满，headless Chrome 被 OOM 杀掉（dmesg 实证）；75 条逐条至少通过一次、无稳定失败，归因宿主资源而非代码。

## 六、偏离与登记

| # | 事项 | 说明 |
|---|---|---|
| 1 | **常量命名出入** | 施工单写作 `EMULATOR_ENV`，实现为 `ENV_EMULATOR`（值 `SANDBOX_TERMINAL_EMULATOR`）——与 `terminal.py` 里既有的 `ENV_*` 命名族一致，**无行为差异** |
| 2 | **已访问集合不跨 Obsidian 往返** | 分屏整体卸载是既有口径，集合清零属必然结果；**登记为已知限制**（重走一次快照），不是缺陷 |
| 3 | **滚动位置还原 jsdom 测不了** | 单测环境量不到 xterm 视口，还原逻辑只能靠实现注释 + 真机观察；**无自动化断言覆盖**，如实登记 |
| 4 | **e2e 取证动作从「切标签」改为 reload** | 常驻使「切标签」不再重建 ⇒ 原取证动作失效；reload 是更强的重挂载，**不是降低标准** |
| 5 | **单次 75/75 未取得** | 宿主内存 OOM（dmesg 实证），见第五节第 6 条 |

## 七、评审遗留（登记不修，后续可领）

1. **快照格式化仍在会话锁内**：已打点观测，未移出锁外——极短尾延迟可能落在锁内。
2. **`pwd` 每分片重复下发**：带宽冗余（分片数 × pwd 长度），无正确性问题。
3. **错误帧无机器可读的 `code` 字段**：前端的「旧后端识别」靠**字符串匹配**「无法识别的终端指令 + attach」，文案一改即失效。
4. **`snapshotParts` 未按连接隔离**：同一会话多连接同时附着时的边界未收敛（当前附着模型下未触发）。

## 八、仍登记不做（③④）

- **③ 终端自定义按键映射**（shift+enter → `ESC+回车`）：前端 xterm.js 5.5.0 **不支持 kitty 键盘协议**，快照带了键盘协议标志也用不起来；映射表存放位置（前端设置 / 本地存储 vs 服务端配置）**立项时定**。
- **④ 系统剪贴板 ↔ 沙箱剪贴板互通**（OSC 52）：前端未实现 OSC 52 处理器；**快照不含 OSC 52 内容**，本轮零副作用。

两项均在 [[current-state.md|当前状态]] 的 TODO 板保留，**待立项**。
