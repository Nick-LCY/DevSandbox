# 文件注入轮任务集（创建沙箱时把宿主文件复制进沙箱）

本目录是沙箱平台**文件注入轮**的任务集，共 4 个工作包，需求来源见 [[prds/file-injection.md|文件注入轮 PRD]]。

文件注入轮在一期本地闭环与控制台模板轮之上补一条数据通道：创建沙箱时用户声明一组宿主文件（`宿主路径:容器路径`），平台把原件复制一份、改属主为沙箱用户、以只读方式挂进容器。机制选型与信任边界的决策依据见 [[architecture/decisions/0012-文件注入采用复制加改属主而非改造挂载预检.md|0012 文件注入采用复制加改属主而非改造挂载预检]]。

**状态：四个工作包全部完成**，Playwright 真机 27 条全绿；看板见 [[current-state.md|当前状态]]。
