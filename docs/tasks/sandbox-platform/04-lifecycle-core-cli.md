# 任务：生命周期核心模块与 CLI

> 实测结论：全部完成标准通过。核心包 `platform/src/sandbox_platform/`（生命周期编排 / 用户与子 ID 段 / 镜像与离线包 / 挂载 / 元数据），薄壳命令行 `platform/cli/sandboxctl.py`，接口文档 `platform/src/sandbox_platform/API.md`，冒烟脚本 `platform/scripts/smoke-lifecycle.sh`（23 项判定全通过，可重复执行）。测试：80 项 pytest 全通过（其中 5 项宿主级测试打 `root` 标记）。
>
> 关键实现约定：沙箱容器固定用 `docker run -d -i` 启动（保持标准输入打开，基础镜像入口的 `exec bash -i` 才不会立即退出）；宿主本地镜像走「导出后注入沙箱守护进程」路径，不依赖镜像仓库；用户声明挂载的宿主路径必须对沙箱用户可读可穿过，否则创建时直接报错。

## 目标
实现沙箱生命周期的可复用核心模块（创建 / 关闭 / 删除 / 列表），并提供只做参数解析与结果打印的薄壳 CLI。一期所有生命周期逻辑必须写在可复用服务模块内，二期直接以同一模块暴露 HTTP API。

## 完成标准
- [x] 代码分层：`platform/src/sandbox_platform/` 内实现核心模块（至少含 `lifecycle.py` 生命周期编排、`userspace.py` 用户与子 ID 段管理、`images.py` 镜像与离线包加载、`mounts.py` 用户声明挂载的解析与应用、`metadata.py` 沙箱元数据存储），`platform/cli/sandboxctl.py` 只做 argparse 解析、调用核心模块、打印结果；核心模块源码内不出现 `argparse` 或 `print(`。
- [x] 单元测试断言核心模块可在无 CLI 环境下导入并被直接调用（测试文件不 import CLI 模块）。
- [x] 创建流程按固定 7 步执行，任一步失败即中断并回滚已完成步骤：① 创建专属用户 ② 登记子 UID/GID 段 ③ 写入并启动 systemd 用户单元（含 enable-linger） ④ 解析并应用用户声明的挂载（解析 `--mount 宿主路径:容器路径[:ro]`，不创建、不修改、不清理其宿主机目录） ⑤ 启动沙箱容器并挂载套接字与用户声明挂载 ⑥ 写入沙箱元数据 ⑦ 输出连接方式与命令提示。
- [x] 未声明任何挂载的沙箱仅挂载套接字即可正常使用：容器内 `docker ps` 正常、可用挂载点只有套接字，删除后不残留任何平台创建的目录。
- [x] 创建后以沙箱用户身份执行 `docker ps`，输出只包含该沙箱的沙箱容器与依赖容器，不含其他沙箱的容器。
- [x] 权限判据：沙箱容器内可操作本沙箱依赖容器；尝试访问宿主其他沙箱用户的 Docker 套接字路径被拒绝（返回权限错误，不是超时）。
- [x] 关闭沙箱：停止沙箱容器与依赖容器（依赖容器是否一并停止由显式参数控制，默认停），保留用户、守护进程、家目录与用户声明挂载的宿主机目录；再次启动沙箱后挂载目录内容原样存在（同一子 UID 段、同一守护进程）。
- [x] 删除沙箱按固定回收清单执行：删除沙箱容器与依赖容器 → 停止并禁用 systemd 用户单元 → 删除用户与家目录 → 回收 `/etc/subuid`、`/etc/subgid` 中的映射段 → 删除平台元数据 → **用户声明挂载的宿主机目录一律不触碰**（平台不创建、不删除、不修改）。
- [x] 删除判据：删除命令执行前打印确认提示，输出平台资源的回收清单，并包含字面量「用户挂载的宿主机目录不受影响」；命令需显式确认参数（如 `--yes`）才真正执行，默认交互式确认。
- [x] 删除后断言：平台创建的资源全部不存在（沙箱容器、依赖容器、守护进程、systemd 单元、用户与家目录、子 UID/GID 段、平台元数据）；用户声明挂载的外部目录仍存在且内容未变。
- [x] 控制面不做 git 操作：`platform/src/sandbox_platform/` 与 `platform/cli/` 全文检索 `git ` 命令调用，匹配数为 0。
- [x] `list` 命令输出表格：沙箱名、状态（运行中 / 已停止 / 已删除）、系统用户、Docker 套接字路径、挂载清单、沙箱容器 ID。
- [x] 幂等与并发：重复删除同一沙箱返回明确的「不存在」结果且不报错；两个并发创建的沙箱拥有不同的系统用户与不重叠的子 UID 段。
- [x] 冒烟脚本 `platform/scripts/smoke-lifecycle.sh` 在干净宿主机上可重复执行：创建 → 关闭 → 删除 → 校验回收清单全部生效。
- [x] 接口文档 `platform/src/sandbox_platform/API.md` 给出各模块对外函数签名与参数表，并注明「一期经 CLI 暴露，二期将由同一模块暴露为 FastAPI 路由」。
