# 文件窗格与 Obsidian 阅读器任务集

本目录是**文件窗格与 Obsidian 阅读器**轮的任务集，共 **8 个任务**，需求来源见 [[prds/file-pane-obsidian.md|文件窗格与 Obsidian 阅读器 PRD]]。

这一轮改造控制台的**终端区**：① 把文件浏览从「全局抽屉」改成**终端的伴生分屏**（可折叠、锚定当前会话的 shell 当前目录、以浏览下载为主、文本预览为辅）；② 新增一个**固定的 Obsidian tab**，全宽双栏 vault 阅读器（左树右预览，markdown 渲染 + wikilink 正向跳转）。支撑链路是 **pwd 通道**——用 shell integration（OSC 1337）把 shell 当前目录报上来。

**状态：01~08 全部 done（2026-11-14 收口；01~06 于 2026-11-13，07 / 08 于 2026-11-14）**（2026-11-12 立项）——立项口径来自**两轮低保真 HTML 原型的逐项拍板**；**无重大架构分歧，不写新 ADR**，机制说明写在 PRD「方案」节（唯 ADR 0004 追加一条修订行——镜像 shell 配置口径对齐，2026-11-14 落，历史表述不改写）。看板见 [[current-state.md|当前状态]]，全轮留档见 [[tasks/file-pane-obsidian/RESULTS.md|RESULTS]]。

**2026-11-13 口径修订（用户拍板，三项）**：① **大文件预览**改「**二次确认 + 进度条加载**」——废除 2 MB 强制截断与「文件过大」提示条，确认后加载**全文**；② **镜像与环境变量补齐**并入 **02**——base image 新增 UTF-8 locale ENV、创建沙箱容器时注入 `SANDBOX_NETWORK`（值 = **实际生效的 docker 网络名**）；③ **Obsidian tab 图标**改用 **Obsidian 官方 logo SVG**（本地资产、运行时零 CDN），不再用 lucide `gem`。验收标准由 **35 条**增至 **38 条**（新增 **OBS-11** / **ENV-01** / **ENV-02**）。

**关键口径（贯穿全轮）**：

| 口径 | 内容 |
|---|---|
| 文件窗格形态 | **终端区分屏**（左终端面板 + 可拖拽分隔条 + 右文件窗格），**默认约 340px**；全局 `DrawerShell` 文件抽屉**退役**、工作区头部「文件」按钮移除 |
| 折叠 | 右缘 **36px** 纯图标竖条，**不显示任何文字**，「展开 / 收起」按钮**固定窗格右上**（展开态在工具条行**最左**——复验修复轮·第二批工具条重排、折叠态在竖条顶部）；折叠态**前端本地记忆**，跨会话关闭 / 重开保持 |
| 入口随会话 | 窗格只在「**存在终端会话且激活的是终端 tab**」时存在；关闭全部会话 ⇒ 窗格消失 + 空态（「**没有终端会话**」+ 新建会话入口）；重开会话恢复且折叠态保持 |
| 定位 fallback 链 | **会话 pwd → 沙箱工作目录（metadata `workdir`）→ 容器根目录 `/`** |
| 跟随策略 | **无自动跟随**（用户彻底放弃：shell 内 `cd` 窗格绝不联动）；唯一联动入口 = 工具条「**回跳**」准星按钮 |
| 回跳 tooltip | 「**跳转到终端当前目录：<路径>**」；pwd 不可得时「**当前会话未上报工作目录**」且按钮禁用 |
| 文件行语义 | **单击 = 下载**（既有口径不变）；**仅文件行** hover 行尾浮现「预览」眼睛按钮（约 **150ms** 淡入、带 `aria-label`、不带文字）并隐藏该行修改时间，**目录行 hover 修改时间保持可见**（复验修复轮·第二批）；工具条列表态专属「**刷新**」按钮（同路径强制重读，预览态不出现） |
| 预览 | **窗格内的第二视图**（非弹层非抽屉）；**`.md` 一律纯文本**（文件窗格内**无 markdown 渲染**）；**大文件（>2 MB）= 二次确认对话框 + 进度条加载 + 全文渲染**（**不截断**、**无「文件过大」提示条**；判断依据取**文件列表条目的 `size`**）；二进制 = 首块 **NUL** 嗅探 → 空态构图 |
| pwd 通道 | 镜像侧 `/etc/bash.bashrc` 注入 **OSC 1337 CurrentDir**（tabby 方案）；前端 `term.parser.registerOscHandler(1337, cb)`（**禁手写扫描器、禁逐帧 `TextDecoder`**）；pwd 是**纯前端产物**，后端会话记录**不加字段** |
| 全屏 | 全屏对象从「仅终端面板」改为「**tabs 条下方的整个内容区**」；仍为**纯 CSS fixed 覆盖**（**禁** `requestFullscreen` / `keyboard.lock`）；不入路由不入存储，换沙箱自动退出 |
| Obsidian tab | tabs 条**最左**的**固定** tab（**Obsidian 官方 logo SVG**（本地资产、零 CDN）+「Obsidian」，不可关闭、无关闭按钮），**独立于终端会话**；激活时**文件窗格隐藏**，切回终端 tab 窗格按原折叠态恢复 |
| Obsidian 布局 | **全宽双栏**（左 vault 树 + 右预览区），中间**可拖拽骑缝把手**（与文件窗格共用同一份组件、常显、直角；左树默认 264px 可拖拽，180 / 520 钳位、预览最小 320 保底，宽度会话内内存态——复验修复轮·第二批修订）；vault 根**按沙箱记在前端本地**（不入后端） |
| 渲染 | 内容列**填满预览区宽度**（保留水平内边距，不设固定上限）；**frontmatter 渲染态隐藏、源码态可见**；渲染器**不放行原始 HTML** |
| wikilink | `\[\[目标\]\]` / `\[\[目标|别名\]\]` / `\[\[#标题\]\]`；兜底 **同目录 → vault 根相对 → 全库递归同名**（带 exec 看门狗超时）；目标不存在 ⇒ 正文顶部就地浅红错误条 |
| 后端 | 新增 **`GET /api/sandboxes/{name}/files/read`**（`path` + `max_bytes`）——复用既有**分层探测**与 **exec 字节泵**，首块 **NUL** 嗅探报二进制，**不拦 `..`**（ADR 0018 既定）；**正文流式返回、元信息走响应头**（二进制标记 / 总字节数 / 截断声明），**正常流程按列表 `size` 请求全量**，`max_bytes` **仅为防护性上限** |
| 镜像与环境 | base image Dockerfile 新增 **`ENV LANG=C.UTF-8`** / **`ENV LC_ALL=C.UTF-8`**（**02 已落地**，镜像**基础层**）；平台起容器时**强制注入** locale（**平台值优先**于用户同名 env，与 `SANDBOX_NETWORK` 同口径，**强制层**）；创建沙箱容器时注入 **`SANDBOX_NETWORK`**，值 = **实际生效的 docker 网络名**（默认 `<沙箱名>-net`；用户指定自定义网络则取自定义值）；**容器内变量**（非 `SANDBOX_PLATFORM_*` 平台参数）、**不写入 metadata**，**创建 / 重启双路径**覆盖 |

## 依赖顺序

```
01 ──┬──▶ 02（镜像）
     │
     └──▶ 03（前端）──▶ 04 ──┬──▶ 05 ──┐
                         └──▶ 06 ──┴──▶ 07 ──▶ 08
```

- **01 是硬前置，不通过不进后续**：镜像注入写法（bash 转义与引号）、sh 降级表现、断线重连 pwd 恢复方案**都在 01 轮实测定**——02 与 03 都按 01 的结论施工，不自行发挥。
- **02 与 03 可并行**：02 动**镜像与核心包**（base-image + 版本 bump + 构建推送 + **locale ENV** + 核心包 **`SANDBOX_NETWORK` 注入**与其单测），03 动**前端**（解析纯函数 + OSC 接线 + 会话缓存），**与 03（前端）仍零文件重叠**；03 的**实现**只等 01 的结论，真沙箱**端到端复验**要等 02 的镜像就绪。**两轮均已收口（2026-11-13）**：02 镜像与核心包侧完成并含**真沙箱复验**；03 前端侧完成，**浏览器端端到端复验的前置已就绪**（04 已于 2026-11-13 落窗格），真机复验归 **08** / 用户验收。
- **04 依赖 03**：窗格定位与回跳都要用会话 pwd。
- **05 依赖 04**：预览是窗格内的第二视图。
- **06 依赖 04**：Obsidian tab 与文件窗格动同一片标签区与内容区布局（04 的折叠 / 隐藏语义是 06 的前提）。
- **07 依赖 06**（渲染与 wikilink 建在 Obsidian 双栏骨架之上），**数据来源**是 05 落地的**只读端点**。
- **08 收口依赖全部**（01~07）。
