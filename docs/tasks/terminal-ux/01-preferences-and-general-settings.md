# 任务：偏好存储层与设置抽屉「通用设置」tab 改造

## 目标

- 建立两个终端交互布尔偏好的前端存取层，默认值均为关闭；读取失败或值非法时回落关闭，用户主动切换后持久化。
- 将设置抽屉现有「后端配置」tab 移到第一位、改名为「通用设置」并设为默认激活；保留「模板」「代理」tab 的既有顺序与行为。
- 在「通用设置」内加入「终端交互」区，放置 `Shift+Enter` 映射和终端右键两个开关。
- 将既有后端地址、访问令牌、测试连接、保存配置表单完整保留在「通用设置」内；不改后端、核心包或连接配置协议。
- 按既有设置 tab、keepMounted、主题令牌、无解释性副标题和中文字体子集约定完成前端接线，并同步新增 / 调整标识到前端 README 标识表。
