# 沙箱平台任务集（控制台模板轮 基础镜像工具层与启动模板）

本目录是沙箱平台**控制台模板轮（基础镜像工具层与启动模板）**的任务集，共 4 个任务，需求来源见 [[prds/console-templates.md]]。

控制台模板轮在一期本地闭环与二期网页控制台之上做两件事：把常用工具装进平台基础镜像（0.3.0），以及在网页控制台上新增「启动模板」——把一套沙箱启动配置存起来、下次一键回填。启动模板是控制台私有能力，核心包与命令行零改动。

## 清单

按依赖顺序排列：

- [[tasks/console-templates/01-base-image-0.3.0.md]] — 基础镜像 0.3.0 通用工具层：apt 装 9 个通用工具包、构建转联网、判定脚本扩到 42 项。
- [[tasks/console-templates/02-template-server.md]] — 模板服务端：模板库落盘、四条接口、`~` 展开、内置模板种子注入机制。
- [[tasks/console-templates/03-template-console.md]] — 模板前端与字体：新建抽屉的加载 / 保存、设置抽屉的模板管理区、字体子集重生成。
- [[tasks/console-templates/04-acceptance-and-docs.md]] — 控制台模板轮真机验收与文档收口：三套测试全绿、两篇架构决策记录、看板与约定同步。

## 依赖图

- 01 无前置依赖，可直接开工。
- 02 无前置依赖，可与 01 并行开工。
- 03 依赖 02：前端要对接模板接口，接口契约先定。
- 04 依赖 01 ~ 03：三套测试与文档收口需要工具层、模板服务端与模板前端全部就位。
- 全部任务都不改动控制面核心包与命令行 `platform/cli/`；模板能力收敛在控制台服务层与网页控制台内。
