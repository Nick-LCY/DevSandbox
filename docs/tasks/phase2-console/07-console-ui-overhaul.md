## 目标
把网页控制台从「四个独立页面」重做为「单页工作台」：左侧边栏常驻沙箱列表与全局工具，右侧工作区承载选中沙箱的摘要、操作与终端会话标签；所有次级操作弹窗化。同时把视觉底座整体换成一套可维护的令牌体系（Tailwind v4 + shadcn/ui + 双主题 + 自托管字体），并让端到端验收脚本与单元测试跟上新的定位方式。本次只动前端，后端服务、命令行与 API 契约一行不改。

## 完成标准
- [x] 单页工作台成型：左侧边栏含沙箱列表（带状态点）、新建沙箱按钮、健康自检、代理设置入口、主题切换；右侧工作区含选中沙箱的头部操作与终端会话标签条。旧四页（列表 / 新建 / 详情 + 终端 / 设置）路由全部退役。
- [x] 弹窗化：新建沙箱、沙箱详情、代理设置、删除确认、关闭终端会话全部走弹窗，弹窗开关状态不入路由（刷新页面自然关闭）。

- [x] 视觉底座：Tailwind CSS v4（`@tailwindcss/vite`）+ shadcn/ui（base-nova 预设）+ `@base-ui/react` 交互原语 + lucide-react 图标；**不引入 Radix**。

### 底座与主题基建
- 接入 Tailwind v4（`@tailwindcss/vite`）与 shadcn/ui base-nova 预设，交互原语统一走 `@base-ui/react`，图标统一走 lucide-react；shadcn 的 `data-*` 变体与 accordion 关键帧内联进样式底座，生产构建不再依赖 devDependencies。
- 颜色令牌全部改写为 OKLCH，alpha 槽位统一挂 `--app-alpha`；聚焦环与三层阴影按各自需要的 alpha 值豁免，不参与全局通道。
- 双主题落地：`<html class="dark">` 切换，默认亮色、不跟随系统，手动切换写 localStorage（键 `sandbox-console-theme`），首帧防闪烁脚本与主题模块用同一套存储键。
- 字体自托管：Noto Sans SC 与 Geist Mono 各自字重实例化后按字符集子集化成 woff2 入库 `public/fonts/`，生成脚本 `platform/console/scripts/build-fonts.sh` 分三步（取源字体 → 生成字符集 → 实例化 + 子集化），任一字重失败则丢弃暂存产物、不留半成品。

### 工作台布局与弹窗迁移
- 外壳重排为左侧边栏 + 右侧工作区；侧栏承载沙箱列表（带状态点）、新建按钮、健康自检、代理设置与主题切换，选中态只用背景高亮。
- 新建沙箱、沙箱详情、代理设置、删除确认、关闭会话五类交互全部弹窗化，全站只有一套弹窗实现（统一外壳 + Base UI Dialog：焦点陷阱、Esc 关闭、焦点归位）。
- 哈希路由收敛为两层；旧四页地址与未知地址一律退回工作台。
- 终端标签改为直接渲染后端会话表：一个标签一个会话，点标签即附着，标签尾 `×` 关闭会话并按「运行中 / 已退出」给两套确认文案；标签序号与会话身份绑定，关中间标签不重排。
- 删除沙箱改两步确认（5 秒武装窗）；终端聚焦时全量拦截带 Ctrl/Meta/Alt 的组合并转发到容器内 shell，浏览器真保留键豁免。

### 测试收尾与真机验收
- data-testid 规范随新结构重写，验收脚本改用「开弹窗 / 两层路由 / 两步确认 / 点已有标签重新附着」四组新动作，废弃旧四页与「后端保留会话」列表的定位方式。
- 单元测试从 67 项补到 120 项，新增覆盖主题存取、标签序号与关闭会话交互、弹窗焦点管理与删除武装窗过期。
- Playwright 真机验收 16 条用例全过（约 4.4 分钟）：生命周期 / 本地构建镜像 / 网页终端（含 `Ctrl+C` 到达容器内 shell、断线后重附着回放、服务重启后旧会话失效）/ 命令行-网页等价性 / 回收清单 / 安全边界。
