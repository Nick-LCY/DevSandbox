# 任务：控制台弹窗抽屉化

> 实测结论：全部完成标准通过。`platform/console/` 前端的三个大面板（新建沙箱 / 沙箱详情 / 代理设置）从居中弹窗改为**右侧滑出、宽度可拖拽的抽屉**；确认类弹窗（删除沙箱 / 停止沙箱 / 关闭终端会话）保留弹窗形态但内容精简；新建沙箱的成功面板整块退役。后端 `platform/src/`、命令行 `platform/cli/`、API 契约**零改动**。
>
> 关键实现约定：抽屉底座用 `@base-ui/react` 1.9.0 自带的 Drawer 原语（**零新增依赖**），三件套是统一外壳 `components/workbench/DrawerShell.tsx`、原语封装 `components/ui/drawer.tsx`、宽度存取 `lib/drawer-width.ts`；三个抽屉**共用一个宽度存储键** `sandbox-console-drawer-width`（默认 40 视口百分比、钳位区间 [20, 80]）；拖拽中只动外壳本地状态、**松手才写存储**；窄屏（视口 < 640px）抽屉占满整屏且**不提供拖拽入口**。
>

## 目标
把三个占用面积大的面板从「居中弹窗」换成「右侧滑出抽屉」，让它们不再遮挡工作区、宽度还能按需拖宽；同时把确认类弹窗里冗余的内容删掉（回收清单预览、两步武装窗），把停止沙箱这类可逆但有副作用的操作补上确认。后端服务、命令行与 API 契约一行不改。

## 实施要点

### 抽屉底座
- **三件套**：`DrawerShell.tsx` 是唯一对外的抽屉外壳（统一标题栏、关闭按钮、正文与底部按钮区）；`ui/drawer.tsx` 只做 Base UI Drawer 原语的薄封装；`lib/drawer-width.ts` 负责宽度的存取、钳位与像素 / 视口百分比换算，读写都包 try/catch（隐私模式下访问 localStorage 会抛异常）。
- **拖拽与落盘**：把手按下时记录起点横坐标与当前像素宽度，拖动中每帧最多更新一次外壳本地状态（避免每像素重渲染整个工作台），**松手才把最终值上抛**并写存储；指针捕获意外丢失按松手收口，防止宽度悬着不落盘。
- **键盘入口**：把手上按左右方向键每次调 2 个百分点（方向与拖拽一致：向左变宽），`Home` 回默认宽度；把手带 `role="separator"` 与 `aria-valuenow`。
- **配色不丢**：抽屉传送挂到 `body`，脱离了 `[data-console-shell]` 作用域，因此面板自己挂 `data-console-shell=""`，选中态与 `color-scheme` 规则照样命中。

### 确认类弹窗精简
- 删除沙箱只说两件事：删了会怎样（容器、网络、守护进程与系统用户都会被回收，不可撤销）、哪些东西不受影响（「用户挂载的宿主机目录不受影响」绿色提示块留在弹窗原位）。
- 停止沙箱弹窗内容是后果说明（容器退出、文件与配置保留、可随时再启动）加一个「同时停止依赖容器」复选框，默认勾选（与命令行默认一致），每次打开都回到默认勾选，上一次取消时的状态不粘到下一次。
- 关闭会话弹窗删掉会话标识行（会话本身已有标题与说明），面板宽度收到 360px。

### 新建沙箱成功行为
- 创建成功直接关抽屉，工作台弹一条成功 toast 并刷新沙箱列表；**不自动选中**新建的沙箱（需要时从左侧边栏选）。
- 创建请求在途时抽屉不响应关闭（Esc / 遮罩 / × 一律不关），与删除、停止弹窗口径一致：请求已经发出，不能半途退出。
