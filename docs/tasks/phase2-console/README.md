# 沙箱平台任务集（二期 控制面服务化与网页控制台）

本目录是沙箱平台**二期（控制面服务化与网页控制台）**的任务集，共 6 个任务，需求来源见 [[prds/phase2-console.md]]。

二期在一期本地闭环之上做两件事：把一期已沉淀的控制面核心模块常驻为 FastAPI 服务，并提供网页控制台（沙箱管理 + 代理设置 + 网页终端）。一期命令行保持原样，一期契约全部不变。

## 清单

按依赖顺序排列：

- [[tasks/phase2-console/01-service-core-api.md]] — 控制面服务骨架与沙箱管理 HTTP 接口：应用工厂、路由、错误映射，以及「镜像强制从宿主注入」的入参开关。
- [[tasks/phase2-console/02-image-proxy-api.md]] — 宿主镜像枚举与代理状态管理接口：本地镜像实时下拉的数据源，代理状态查看与重启。
- [[tasks/phase2-console/03-web-terminal.md]] — 网页终端：伪终端会话管理、会话表持久化与 WebSocket 双向桥接。
- [[tasks/phase2-console/04-console-frontend.md]] — 网页控制台前端：沙箱列表、新建沙箱、沙箱详情与终端、代理设置四个页面。
- [[tasks/phase2-console/05-acceptance-regression.md]] — 二期端到端验收与一期回归复验：网页全流程演练、与命令行等价性核对、一期无回归。
- [[tasks/phase2-console/07-console-ui-overhaul.md]] — 控制台 UI 全面改造：前端整体重做为单页工作台，视觉底座换成 Tailwind v4 + shadcn/ui + 自托管字体 + 双主题。

## 依赖图

- 01 是其余任务的地基：应用骨架、路由注册约定、依赖注入与错误映射约定都在这里定型。
- 02 与 03 都依赖 01，两者互不依赖，可并行开工。
- 04 依赖 01 + 02 + 03：前端要同时对接沙箱接口、镜像枚举、代理接口与终端协议。
- 05 依赖 01 ~ 04：验收需要完整的网页控制台才能跑通全流程。
- 07 无前置依赖：在已完成的前端工程上做视觉与信息架构改造，后端接口、命令行与 API 契约一律不变。
- 全部任务都不改动一期命令行 `platform/cli/sandboxctl.py` 的行为；一期核心包的既有契约（挂载、镜像两层、回收、免 root 分层）一律不变。
