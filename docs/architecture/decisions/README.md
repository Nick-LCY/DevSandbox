# 架构决策记录（ADR）

每个重要架构决策一个文件，命名 `NNNN-短标题.md`（如 `0001-项目定位与三期路线.md`）。

## 模板

```
# NNNN. 标题

- 日期：YYYY-MM-DD
- 状态：提议 | 已接受 | 已废弃

## 背景
（为什么需要这个决策）

## 决策
（决定了什么）

## 影响
（带来的后果，诚实写出代价）

## 相关决策
（相关 ADR 的链接与一句话说明）
```
