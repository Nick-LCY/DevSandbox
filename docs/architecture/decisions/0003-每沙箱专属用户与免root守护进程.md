# 0003. 每沙箱专属用户与免 root 守护进程

- 日期：2026-10-29
- 修订：2026-10-29（挂载契约修订：套接字为唯一固定挂载，其余挂载由用户声明）
- 状态：已接受

## 背景

沙箱必须满足三条硬要求：agent 拿不到宿主机 root；agent 看不到也影响不了别的沙箱；但 agent 在沙箱内仍需要 Docker 能力（要能自己起 Postgres、MinIO、Logto 这些依赖容器）。

把沙箱容器交给宿主机 root 下的 Docker 守护进程管理最省事，但 agent 一旦拿到套接字，就能看到甚至停掉所有沙箱的容器——隔离直接失效。

需要一套「每个沙箱一套身份、一套守护进程」的结构，让 Docker 能力与隔离同时成立。

## 决策

### 1. 三层结构

| 层级 | 组成 | 职责 |
|---|---|---|
| 宿主机 | 控制面逻辑 + 平台数据 | 编排沙箱生命周期，维护镜像与挂载契约 |
| 每用户守护进程 | 沙箱专属 Linux 用户下的免 root Docker 守护进程 | 起停沙箱容器与依赖容器，维持内部桥接网 |
| 容器层 | 沙箱容器（agent 执行世界）+ 依赖容器 | 承载真正的工作负载 |

沙箱容器与依赖容器都归该守护进程管。

### 2. 专属用户与子 UID/GID 段

- 每个沙箱创建一组专属 Linux 用户，分配独立的一段子 UID/GID 段。免 root 容器需要映射容器内的多个用户 ID，没有子 UID/GID 段就无法映射。
- 守护进程以 systemd 用户级服务单元启动，并用 linger 保活，保证用户未登录时守护进程仍在运行。
- 守护进程的套接字挂载进沙箱容器；沙箱容器本身也由该守护进程启动，不由宿主机 root 的 Docker 启动。

### 3. 容器内可见范围

沙箱容器内执行 `docker ps` 只看得到本沙箱的沙箱容器与依赖容器，看不到宿主机上其他沙箱的容器。

agent 进程运行在用户命名空间内，监禁层级比普通容器更深。

### 4. 生命周期语义

| 操作 | 动作 | 保留物 |
|---|---|---|
| 创建 | 建专属用户与子 UID/GID 段 → 启动守护进程 → 由该守护进程启动沙箱容器，并挂入套接字与用户声明的挂载 | — |
| 关闭 | 停止沙箱容器；可顺带停止依赖容器释放内存 | 守护进程、专属用户及其家目录、子 UID/GID 段记录、用户声明挂载的宿主机目录 |
| 删除 | 回收平台创建的一切：沙箱容器、依赖容器、守护进程、专属用户及其家目录（含依赖数据存储）、子 UID/GID 段记录、平台元数据 | 用户声明挂载的宿主机目录（平台不创建、不删除、不修改） |

### 5. 网络模型

- 沙箱容器与依赖容器同属一张内部桥接网，按容器名互访，连接串形如 `postgres://postgres:5432`。
- 不做宿主机端口发布，不用 nsenter 把宿主机网卡桥接进容器。
- 三期做网页 URL 预览时，由免 root 守护进程把容器端口发布到宿主机回环地址，再由宿主机上的网页反向代理接走，不暴露到局域网。

### 6. 资源配额

- 建议每沙箱 2 核 / 4GB 内存起步。
- 免 root 容器的 CPU 与内存限额依赖 systemd 用户级 cgroup 委托，这是**一期必须先打样验证的前置项**：目标宿主机若不支持该委托，免 root 模式与配额都不成立。

### 7. 厚沙箱模式（可选，优先级低）

- 保留「特权内嵌 Docker」作为可选模式：沙箱容器以特权方式运行，并在内部自带一套 Docker，agent 看到的接口与普通沙箱完全一致。
- 切换方式按沙箱配置决定，默认走免 root 模式。
- 该模式属三期能力，优先级低。

## 影响

- agent 能看到并可能删除自己的沙箱容器——因为套接字在它手里。这是本方案明确接受的代价，靠三条兜底：代码目录由用户自行挂载并交给 git 管、依赖状态存在用户家目录、控制面能在秒级重建容器。
- 免 root 网络走用户态网络栈，吞吐与延迟不如宿主机原生网络栈，部分内核网络特性不可用。
- 每个沙箱一套用户加守护进程，宿主机资源随沙箱数线性增长；删除流程必须可靠清理，否则残留守护进程与子 UID/GID 段会耗尽宿主机资源。
- 端口只发布到回环地址，外部访问必须经宿主机反向代理；三期实现之前，局域网内无法直接访问沙箱端口。
- cgroup 委托是一期前置验证项，若验证失败要回到本决策重新评估免 root 模式，而不是在后续阶段临时绕过。
- 厚沙箱模式削弱隔离（容器特权接近宿主 root 权限），只作为免 root 打样验证失败时的备选或特殊场景选项，不作为默认。
