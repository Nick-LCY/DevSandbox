- **移除终端空闲回收** — **已完成（2026-11-09）**。终端会话的空闲回收机制整体下线：后台巡检线程、「距上次附着 ≥30 分钟即自动关闭」的判据、`reclaimed` 退出原因与 `SANDBOX_TERMINAL_IDLE_TIMEOUT` 环境变量一并移除。会话**只有三种用户可感知的结束方式**——用户主动删除（`closed_by_user`）、容器内进程自己退出或崩溃（`exited`）、沙箱删除（容器销毁连带 exec 死亡，走 `exited`，前端提示异常结束属预期）；另有服务退出兜底（`shutdown`，非用户可感知）。**保留的口径**：服务重启仍作废全部会话并做启动清扫（跨实例保护不变）、名额语义不变（全局 20 / 单沙箱 5，已退出仍占、需手动移除，超限报错改为引导在终端标签条手动关闭）。**收益**：断开标签页后会话与进程在后台继续存活，重开标签页能接回同一 shell 现场。**已知后果**：名额会持续积压，已登记待办（见下方 TODO）。决策依据见 [[architecture/decisions/0017-移除终端空闲回收.md|0017]]。
