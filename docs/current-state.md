- 2026-10-30：二期任务 04 审查修复轮——reviewer 结论「无严重问题」，4 项中等问题与 11 项建议逐条修完。**路由容错**：沙箱名里的畸形百分号编码（如 `#/sandboxes/%`）会让 `decodeURIComponent` 抛 URIError，异常经路由快照冒泡到渲染，整站白屏；现在解码失败一律退回沙箱列表页，并补一条畸形编码的路由单测。**终端重连风暴**：退避计数原先在 WebSocket 握手成功时就清零，服务端握手后立刻关闭会退化成每 500ms 一次的无限连接风暴；现在计数只在收到服务端 `hello` 帧或连接稳定存活超 5 秒后才清零，连续失败 10 次即停掉自动重连，改由用户点「重试连接」手动触发。**定位符缺失**：`index.html` 的静态占位带 `page-layout-title`，React 挂载后占位被清空，README 承诺的定位符实际不存在；现在品牌名元素自带 `data-testid="page-layout-title"`。采纳建议 11 项：终端卸载补 `fitAddon.dispose()`、`new WebSocket(...)` 包 try/catch（地址非法走失效状态而不是抛异常打断 effect）、操作提示条拆成功 / 失败两种样式（删除 / 启动失败用错误样式）、容器路径重复在前端先拦（少一次往返）、代理状态摘要与后端健康自检两处死代码接到页面上（摘要接设置页顶部，健康自检接外壳顶部）、镜像下拉在页面重新可见时补拉一次、服务端 error 帧给独立的告警样式、终端标签标题改单调递增计数器（关掉中间标签后不再重名）、删除确认弹窗支持 `Esc` 关闭、`docker exec` 命令行回归断言升级为尾部整体断言并补 `Privilege(enabled=True)` 的 sudo 分支用例、`websockets` 依赖下界补注释说明。前端 typecheck / vitest（58 项）/ build 全过，后端 288 项 pytest 全通过（基线 287 项，新增 1 项）。命令行 `platform/cli/sandboxctl.py` 源码仍一行未改。
- 2026-10-30：二期任务 03 审查修复轮——修掉 1 项严重问题与 7 项中等问题，另落地 8 项采纳建议。严重问题：**输入写阻塞导致终端双向死锁**——伪终端主端是阻塞的，用户粘贴大文本或容器内进程停止读 stdin 时，I/O 线程卡在写操作上不再读主端，输出写满后容器内 shell 卡在写 stdout，两边互等，Ctrl-C 都送不进去；现在主端改为非阻塞（写不进去就留着字节等下一个「可写事件」，单次写上限 4 KiB），I/O 线程永远不会停止读输出。中等问题：**容器内 shell 残留**——杀宿主侧容器 exec 客户端并不会终止容器内的 bash，服务重启后容器里会堆积无主 shell，接口文档「容器内进程一并收掉」的承诺失真；现在会话关闭与启动清理都会按注入的环境标识在容器内收掉残留进程（按环境变量匹配，覆盖整棵进程树；容器已删时静默跳过）。其余修复：清理遗留进程改用「进程身份指纹（进程组号 + 启动时刻）+ 杀前复核」防进程号复用误杀（解释器支持时再加进程句柄）、僵尸进程立即判定不再白等 3 秒宽限期、`terminate` 幂等且必须带会话标识复核、附着计数不再多减（先登记附着再发首帧）、输入超限改丢**最新**字节并给客户端发一条提示帧、会话数加全局 20 与单沙箱 5 的上限并回收空闲 30 分钟的无主会话（常量可用环境变量覆盖）、窗口大小变更纳入落盘（合并写，避免拖窗口时的写放大）、启动清理加跨实例保护（会话记录带宿主进程号，另一个实例还在用就不动它）。采纳建议：解释器路径缺失时直接报错不再静默降级、回放快照按 64 KiB 切帧、主端文件描述符在 I/O 线程退出后再关、WebSocket 异常兜底补宽异常捕获、容器内 shell 探测结果按容器名进程内缓存、附着与断开与退出的落盘移出事件循环线程（后台线程合并写）。命令行 `platform/cli/sandboxctl.py` 源码仍一行未改。测试 287 项 pytest 全通过（基线 272 项，新增 15 项）。
