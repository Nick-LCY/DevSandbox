# 控制台终端全步方案 + 前端实例常驻

- **口径说明（重要）**：本轮**没有先立 PRD**——需求以「2026-11-17 登记的 pi × 控制台终端四项待办」+ 2026-11-18 拍板的施工单（全步方案）推进。**本文是交付后补记**（2026-11-19）：目标与非目标按交付事实回填，验收标准逐条挂证据。它不是设计前的需求发散，**不得**被当作「本轮当时的设计输入」引用。
- 决策依据：[[architecture/decisions/0020-控制台终端采用后端模拟器与快照接入.md|ADR 0020 控制台终端采用后端模拟器与快照接入]]（已接受）。任务集见 [[tasks/console-terminal-emulator/README.md|控制台终端全步方案任务集]]，全轮数字见 [[tasks/console-terminal-emulator/RESULTS.md|全轮收口留档]]。

## 背景

控制台网页终端的两条主线症状同源：**终端状态没有权威持有者**。

1. 每个会话的 xterm.js 实例**不是常驻的**（`key={activeId}`），切标签即销毁重建 ⇒ pi 全屏期间开启的 DEC 私有模式（鼠标 1000/1002/1003/1006、焦点上报 1004、括号粘贴 2004、备用屏 1049）随实例归零，pi 不重发 ⇒ 鼠标 / 焦点 / 括号粘贴失效。
2. 重建靠**整段重放 256 KiB 环形缓冲**，历史里的终端探测（kitty 键盘查询、DA1、主题色查询）被新实例**再答一遍**，应答经 WS 写进 PTY ⇒ pi 退出后 bash 回显乱码（用户实测）。

pi 侧对此无解（这些状态本来就属于终端），必须在控制台这一层解决。

## 目标

- **症状①②根治**：任何重建路径（切标签、刷新页面、Obsidian tab 往返、断线重连）后，鼠标 / 焦点 / 括号粘贴 / 备用屏**自动恢复**；探测请求**不再被再应答**。
- **终端标签之间实例常驻**：切标签不再销毁重建 xterm 实例，未访问过的会话不自动附着。
- **兼容不破**：旧前端 / 旧后端在混搭组合下都不崩（各自降级），开关可关停新能力。
- **零新增进程模型**：不新增常驻进程、不新增端口、不改核心包与命令行。

## 非目标

- **不做终端自定义按键映射**（原待办 ③，shift+enter → `ESC+回车`）：前端 xterm.js 5.5.0 **不支持 kitty 键盘协议**，快照带了键盘协议标志也用不起来；**仍登记待立项**。
- **不做系统剪贴板互通**（原待办 ④，OSC 52）：快照**不含** OSC 52 内容，本轮零副作用；**仍登记待立项**。
- **不改 Obsidian tab 的卸载口径**：切到 Obsidian tab 时分屏**整体卸载**（既有约定与 e2e 断言不动）。
- **不回放历史**：快照只恢复**活动屏 + 光标 + 模式**，主屏滚动历史（pi 全屏期间）不回放；服务端回滚深度 1000 行、前端 5000 行，差异不拉平。
- **不改会话生命周期**：不做空闲回收（[[architecture/decisions/0017-移除终端空闲回收.md|ADR 0017]] 不变），不做会话自动清理。

## 方案

分四步，前两步是本轮的主线（施工单前七步按交付面归并），第三步是施工单**步骤 8 的增量**，第四步收口：

1. **服务端常驻终端模拟器**：每会话一份 pyghostty 实例（进程内 libghostty-vt），输出并行喂、几何与 PTY 恒一致；导出「画面 + 光标 + 模式」的 VT 恢复流。两条红线：结构体字段**逐字段显式 ctype**、**不注册应答回调**。
2. **接入协议换代**：`attach`（报尺寸）→ 对齐会话（先模拟器后 PTY，失败回滚）→ 静默窗口（0.12 s / 上限 0.8 s）→ `snapshot` 分片（48 KiB 原文 / base64 / 带 pwd）→ 续实时流；旧客户端 1 秒超时回退环形缓冲回放；**迟到的 `attach` 补发快照**（不新开流）；`SANDBOX_TERMINAL_EMULATOR` 可关停。
3. **前端实例常驻**：删掉 `key={activeId}`，改为终端栈常驻槽位 + `display:none`；只挂载「已访问过的会话」；变可见 refit、滚动位置按距底部还原；焦点回填改为按会话的**请求序号**。
4. **验收与文档收口**：e2e 新增 reload 强制重挂载取证、门禁全量、ADR + 任务集 + 约定 + 看板同步。

细节与代价见 [[architecture/decisions/0020-控制台终端采用后端模拟器与快照接入.md|ADR 0020]]；协议帧表与兼容矩阵以 `apps/web/backend/API.md` 12.3 为准。
