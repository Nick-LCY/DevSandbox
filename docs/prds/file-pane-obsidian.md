## 背景

控制台的终端区目前只有终端本身。运行期文件传输轮（[[prds/runtime-file-transfer.md|运行期文件传输]]）交付了浏览沙箱文件的能力，但它的形态是**一个全局抽屉**：入口是工作区头部的「文件」按钮，落在 `DrawerShell` 里，浏览的是**自己上一次停下的目录**，与用户正在敲命令的那个 shell **没有任何关系**。用户在沙箱里跑 agent 时，真正要反复做的是「看一眼当前 shell 所在目录有什么」——这条路径今天要走「关掉抽屉 → 点终端 → 记住路径 → 重新开抽屉 → 手动敲路径」，来回三段。

同时，控制台**没有阅读沙箱内文档的界面**。沙箱里放的是 markdown 笔记、说明文档、agent 产出物，用户只能在终端里 `cat`，而终端不渲染 markdown。

本需求线做两件事，外加一条支撑通道：

1. **文件窗格**：把文件浏览从「全局抽屉」改成**终端的伴生分屏**——右侧一块可折叠面板，锚定当前终端会话的 shell 当前目录，以**快速浏览 / 下载**为主、**文本预览**为辅。
2. **Obsidian 阅读器**：新增一个**固定 tab**，全宽双栏的 vault 阅读器（左树右预览），markdown 渲染 + wikilink 正向跳转。
3. **pwd 通道**（支撑项）：用 shell integration（OSC 1337）把 shell 的当前目录报上来，文件窗格据此定位；这是「窗格锚定会话」的**唯一数据来源**。

两条能力都要先回答「当前在哪」——前者要 shell 的 `pwd`，后者要一个用户指定的 **vault 根**。两者都采用**前端本地记忆**，不进后端。

## 目标

- **文件窗格随会话**：终端区改成「左终端面板 + 中间可拖拽分隔条 + 右文件窗格」的三段式；窗格**锚定当前激活的终端会话**，定位到它的 shell 当前目录。
- **窗格可折叠**：折叠为右缘一条 **36px** 纯图标竖条（不显示任何文字），「展开 / 收起」按钮**固定在窗格右上角**（展开态在工具条行右端、折叠态在竖条顶部）；折叠状态**前端本地记忆**，跨会话关闭 / 重开保持。
- **入口随会话存在**：文件窗格只在「存在终端会话且激活的是终端 tab」时存在；关闭全部会话后窗格整体消失，内容区显示空态并给出新建会话入口。
- **浏览与下载为主、预览为辅**：文件行单击仍即下载（沿用既有下载通道与进度 UI）；hover 文件行行尾浮现「预览」按钮，进入窗格内的第二视图做**纯文本**预览；**大文件（>2 MB）走二次确认 + 进度条加载、不截断**。
- **镜像与环境补齐**（并入任务 02）：base image 补 **UTF-8 locale ENV**；创建沙箱容器时注入 **`SANDBOX_NETWORK`**（= **实际生效的 docker 网络名**）。
- **Obsidian 阅读器**：固定 tab、全宽双栏、vault 树 + markdown 预览，支持 wikilink 正向跳转。
- **pwd 通道**：镜像侧注入 OSC 1337 上报 + 前端用 xterm 的 OSC 处理器解析，**pwd 是纯前端产物**，后端会话记录不加字段。
- **全屏范围扩大**：全屏按钮的全屏对象从「仅终端面板」改为「tabs 条下方的整个内容区」，两种 tab 各自整块全屏。

## 非目标

以下条目**本轮明确不做**，写在这里是为了避免后续被当遗漏：

- **窄窗口适配 / overlay 降级**：窗口过窄时不做折叠成浮层、不做遮罩降级、不做移动端适配。
- **自动跟随 pwd**：**彻底放弃**——shell 里 `cd` 时窗格**绝不联动**。唯一联动入口是工具条的「回跳」准星按钮。
- **折叠竖条上的回跳按钮**：定稿去除。竖条上**只有「展开 / 收起」这一个按钮**（固定在窗格右上角，折叠态位于竖条顶部），不放回跳、不放上级目录等其它按钮。
- **文件窗格内的 markdown 渲染**：文件窗格里的 `.md` **一律按纯文本预览**；markdown 渲染能力**专属 Obsidian tab**。
- **图片内嵌语法**：不支持 `!\[\[嵌入\]\]` 这一类写法。
- **反向链接、全文搜索、图谱视图、标签面板**：本轮的 Obsidian tab 只做「树 + 渲染 + 正向 wikilink 跳转」。
- **文件窗格 → 终端的反向 `cd` 联动**：文件窗格不向终端发任何命令。
- **Obsidian 别名页、嵌入语法、标签 / 搜索语法**：`\[\[目标|别名\]\]` 只作为显示别名，不生成别名页；不做嵌入语法、不做 `#标签`、不做 `query:` 搜索语法。
- **pwd / vault 根 / 折叠态的后端持久化**：三者**全部前端本地记忆**，后端不落字段、不加接口。

## 方案

### 一、文件窗格（分屏）

**布局**：终端区分三段——左**终端面板** + 中间**可拖拽分隔条** + 右**文件窗格**（默认宽约 **340px**）。终端面板有**最小宽度钳位**（拖拽分隔条时终端面板不会被压没）；分隔条可拖拽调整窗格宽度。

**视觉合并**（2026-11-14 复验修复轮）：终端面板右缘为**直角**、与文件窗格**零间隙贴合**；文件窗格**四边完整 border**、**仅右侧圆角**；两者接缝呈现为 **drawer 风格的骑缝把手**（分隔条本身的 role / aria / 拖拽语义不变）。窗格列表态结构为**拍平的三段**——**固定工具条 + 固定列表头 + 直通滚动列表贴满窗格**（不做「窗格内 padding 再包一层表格 / 滚动区」的嵌套结构）。

**抽屉退役**：现有全局 `DrawerShell` 文件抽屉形态**整体退役**，工作区头部的「文件」按钮**移除**——抽屉入口在本轮之后**不复存在**（文件浏览只有「终端旁的窗格」这一个入口）。

**折叠**：窗格可折叠为右缘 **36px** 纯图标竖条，竖条上**不显示任何文字**；「**展开 / 收起**」按钮**固定在窗格右上角**（展开态在工具条行右端、折叠态在竖条顶部）。折叠状态记在前端本地（localStorage），**跨会话关闭 / 重开保持**（关掉终端会话再新建，窗格仍是折叠态）。

**入口随会话**：文件窗格是**终端 tab 的伴生物**——只在「**存在终端会话且激活的是终端 tab**」时存在。关闭全部会话 ⇒ 窗格整体消失，内容区显示空态（标题「**没有终端会话**」+ 新建会话入口）；重开会话后窗格恢复，**折叠态保持**。

**定位 fallback 链**（自上而下，取第一个可得的）：

1. **会话 pwd**（OSC 1337 上报，见第二节）；
2. **沙箱工作目录**（沙箱 metadata 里的 `workdir`）；
3. **容器根目录 `/`**。

**无自动跟随**：shell 内 `cd` 时窗格**绝不联动**——窗格停在用户最后导航到的位置。唯一的联动入口是工具条的「**回跳**」准星按钮：

- tooltip 固定格式「**跳转到终端当前目录：<路径>**」，路径随会话 pwd 更新；
- 窗格**已在目标目录时按钮禁用**；
- 点击即导航到目标目录。

**pwd 不可得时降级**：会话 shell 不支持 OSC 上报（如 `dash` / `sh`）⇒ 回跳按钮**禁用**，tooltip 改为「**当前会话未上报工作目录**」；窗格**维持 fallback 起点**（沙箱工作目录或容器根），不报错、不空转。

**导航**：列表点击切换目录（目录行进目录），顶部**面包屑**逐级可点、**当前层是纯文本**（不可点）；进入预览态后**面包屑恢复可点**，用于从预览返回对应目录的列表（避免预览成为死胡同）。**「同路径导航强制重读」的既有约定继续适用**——点当前路径也必须重新拉数据，不依赖 effect 因同值 state 不重跑。

**文件行语义**：

- **单击文件行 = 下载**（既有口径不变，走既有下载通道与进度 UI）；
- **hover 文件行**，行尾浮现「**预览**」眼睛图标按钮（约 **150ms** 淡入，带 `aria-label`，**不带文字**）；
- **工具条「刷新」**（2026-11-14 复验修复轮新增）：**列表态专属**——点击按当前路径**强制重读**列表（与「同路径导航强制重读」同一机制）；**预览态不出现**刷新入口。

**预览 = 窗格内的第二视图**（不是弹层、不是抽屉）：

- **返回栈**：返回按钮 + `Esc` 等价；**栈为空时隐藏返回钮**；
- **工具条** = 返回 + 文件名 / 大小 + 复制按钮；
- **正文**：等宽字体 + **行号槽**；
- **`.md` 一律按纯文本预览**——**文件窗格内无 markdown 渲染**（渲染能力专属 Obsidian tab）；
- **复制**：点击后图标变**对勾**约 **1 秒**后复原，**成功零 toast**（沿终端剪贴板「成功零反馈」口径），**失败才 toast**；
- **大文件（>2 MB）不截断**：点击预览时若文件**超过 2 MB**（判断依据 = **文件列表条目的 `size` 字段**，int 字节数），先弹**二次确认对话框**（提醒内容超过 2 MB、是否要预览；**确认才发起读取**，**取消不发起请求**）；确认后以**进度条**加载（进度 = **已接收字节 / 该条目的 `size`**），加载完成渲染**全文**——**不再有任何「文件过大」提示条**；**小文件直接加载、不出现进度条**；
- **二进制判定**：读**首块**做 **NUL 字节嗅探** ⇒ 命中则渲染**空态构图**（居中线框图标 +「**二进制文件无法预览**」+ 描边「**下载文件**」按钮）；
- **仅支持 UTF-8**：解码失败同样按「无法展示」处理。

### 二、pwd 通道（shell integration）

**镜像侧注入**（走基础镜像，不做运行时挂载）：base-image 的 `/etc/bash.bashrc` **追加**一段——**保留原 PS1 + 追加 OSC 1337 CurrentDir 序列**。采用 tabby 方案的写法：

```
export PS1="$PS1\[\e]1337;CurrentDir="'$(pwd)\a\]'"
```

（**bash 转义与引号按实现校准**——最终写法由 01 打样轮实测定稿，02 轮按其落地。）注入后**镜像版本 bump 并构建推送**。

**非登录 shell 的读取机制**：控制台的终端会话以 `bash -i` 方式起交互 shell。bash 的读取规则是——**交互式非登录 shell 会读 `~/.bashrc`（用户级，若存在）与 `/etc/bash.bashrc`（系统级；Debian 构建把 `SYS_BASHRC` 编译成了 `/etc/bash.bashrc`）**；**不会**读 `/etc/profile` 与 `/etc/profile.d/*`（那些只由**登录** shell 经 `/etc/profile` 拉起），也**不会**读 `~/.bash_profile` / `~/.profile`（登录 shell 才读）；**非交互** shell 则**一个 rc 文件都不读**。

**注入点为什么选 `/etc/bash.bashrc`**：① **系统级生效，不依赖容器内的用户家目录**——容器可能以不同用户跑 shell（`~` 指向不同的家目录，甚至没有可写家目录），写进 `/etc/bash.bashrc` 则对**所有用户**的交互式非登录 shell 一律生效；② **交互式非登录 shell 确定会读它**——`bash -i` 形态必然经过这一步，既不需要登录、也不依赖 profile 链。

**降级**：`dash` / `sh` 不支持该 PS1 语法 ⇒ **自然降级**（会话不上报 pwd ⇒ 回跳按钮禁用，见第一节）。

**前端解析**：用 xterm.js 的 OSC 处理器接管，**禁止手写字节流扫描器**：

```ts
term.parser.registerOscHandler(1337, (data) => { /* 解析 1337;CurrentDir=<path> */ });
```

xterm 的状态机负责跨帧序列边界（一条 OSC 序列可能被拆到两帧里），手写扫描器会引入新的解码口径。

**解析逻辑收敛**为 `src/lib` 下的**独立纯函数模块**并配**单元测试**：解析 `1337;CurrentDir=<path>`、校验是**绝对路径**、过一遍既有的 `normalizeContainerPath`（`src/lib/file-transfer.ts`）。**禁止引入逐帧 `TextDecoder`**——既有 TODO「终端中文间歇乱码」点名的正是这一片区域，不得引入新的解码口径。

**pwd 是纯前端产物**：按**会话**在前端内存里缓存，**后端会话记录不加字段**。**断线重连后须触发一次提示符刷新**（例如发一个空行或触发一次 resize）以重新拿到 pwd——因为重连后 shell 不会主动再报一次。

### 三、全屏（口径变更）

全屏按钮（tabs 条最右，既有）的**全屏对象**从「仅终端面板」改为「**tabs 条下方的整个内容区**」：

- **终端 tab 激活** ⇒ 全屏的是**分屏整体**（终端面板 + 文件窗格一起）；
- **Obsidian tab 激活** ⇒ 全屏的是**双栏整体**。

全屏层内 **tabs 条保持可见、可正常切 tab、可退出**。实现仍为**纯 CSS fixed 覆盖**——**不得**改用 `requestFullscreen`、**不得**用 `navigator.keyboard.lock`（既有禁令不变）。全屏状态**不入路由、不入存储**；**换沙箱自动退出全屏**（既有口径不变）。

### 四、Obsidian tab

**固定 tab**：位于 tabs 条**最左**，图标 + 文字——**Obsidian 官方 logo SVG**（本地资产，见第六节）+「**Obsidian**」文字。该 tab **不可关闭、无关闭按钮**，且**独立于终端会话**存在（**没有任何终端会话时仍然可用**）。

**与文件窗格的联动**：文件窗格是终端 tab 的伴生物 ⇒ **激活 Obsidian tab 时文件窗格隐藏**；切回终端 tab 时窗格**按原折叠态恢复**。

**布局**：**全宽双栏**——左 **vault 树** + 右**预览区**，中间一条细**分隔线**（**无拖拽**）；左右栏 **header 高度同源对齐**（共用同一高度令牌，2026-11-14 复验修复轮补）。

**vault 根**：

- **未设根** ⇒ 右侧显示**引导态**（居中）：书本线框图标 +「**选择一个目录作为 vault 根**」+「**使用沙箱工作目录**」描边按钮 + **路径输入框** +「**打开**」按钮——**两条入口都可用**；
- **已设根** ⇒ 左栏顶部显示「**vault 根：<路径>**」+「**更改**」小按钮（点击回到引导态并**预填原根**）；
- vault 根**按沙箱记在前端本地**（localStorage），**不入后端**。

**vault 树**：**树形展开风格**（三角箭头旋转、缩进层级线）；**只列目录与 `.md` 文件**；目录可展开 / 收起，**展开态按路径在前端本地记忆**。左栏 header 提供「**刷新**」按钮（2026-11-14 复验修复轮新增）：失效目录缓存后**按当前展开态重拉**，**保留选中与阅读位**、**不重读正文**。

**预览**：**markdown 渲染**为主视图。工具条 = **返回**（历史栈）+ 文件名 / 大小 + 「**渲染 / 源码**」**分段切换** + 复制。

- **渲染态**：内容列**填满预览区宽度**（保留水平内边距，**不设固定上限**）；支持标题层级、**深底代码块**、列表、**任务列表（静态不可勾）**、引用块、行内码、粗体；
- **大文件（>2 MB）**：与**文件窗格预览同口径**——**同一个二次确认对话框** + **同一个进度条**，确认后加载并渲染**全文**（**不截断**）；两处预览**共用同一条只读端点**，行为**必须一致**；
- **frontmatter**（`---` 包裹的 YAML）**渲染态隐藏、源码态可见**；
- 渲染器**不放行原始 HTML**（react-markdown 默认即如此，不额外开启 `rehype-raw`）。

**wikilink**：

- **语法**：支持 `\[\[目标\]\]` / `\[\[目标|别名\]\]` / `\[\[#标题\]\]`；
- **样式**：**强调色 + 虚线下划线**；hover 显示**黑色小 tooltip**，内容是**解析后的目标路径**，须**防视口裁切**；
- **解析兜底顺序**：① 同目录 → ② vault 根相对路径 → ③ **全库递归同名匹配**（递归列举**带 exec 看门狗超时**）；
- 解析结果**过 `normalizeContainerPath`**；
- **点击存在目标** ⇒ 沿**预览历史栈**推入目标渲染视图；
- **点击不存在目标** ⇒ 正文顶部**就地**浅红错误条「**链接目标不存在：<名>**」，**可手动关闭**，**不跳转、不弹 toast**。

**复制**：**渲染态复制 markdown 源文**，**源码态复制原文**；对勾动画口径与文件窗格预览一致（图标变对勾约 1 秒后复原，成功零 toast，失败才 toast）。

### 五、后端只读端点（支撑两处预览）

新增 **`GET /api/sandboxes/{name}/files/read`**，查询参数 **`path`** 与 **`max_bytes`**：

- **正文按流式字节返回**（复用下载通道的流式形态）；**二进制标记 / 截断声明 / 总字节数等元信息走响应头**——前端拿到响应头即可**先判二进制早退**，再按「**已接收字节 / 响应头中的总大小**」驱动**进度条**（既有下载通道已有同款「fetch 流式读 + 按 `Content-Length` 算进度」的实现先例）；
- **复用核心包既有分层探测**（普通文件放行、FIFO / 设备 / 套接字一律拒——防挂起）与 **exec 字节泵能力**（与下载通道同一套资产，见 [[architecture/decisions/0018-运行期文件传输机制选型.md|ADR 0018]]）；
- 读取**首块**做 **NUL 嗅探**，命中则在响应头给出**二进制标记**；
- **`max_bytes` 语义保留为防护性上限**：超限仍截断并在响应头**声明截断**；但**正常流程前端按文件列表条目的 `size` 字段请求全量**——截断提示条 UI 删除后，**前端正常路径永远不应看到截断声明**；
- **路径校验沿用既有口径**：绝对路径 + 拒 NUL + 词法校验，**不拦 `..`**——容器内的权限由容器自身决定（[[architecture/decisions/0018-运行期文件传输机制选型.md|ADR 0018]] 既定）；
- **错误固定中文文案沿用传输轮文案体系**（`{"detail": "<中文>"}`，容器内 stderr 原文只进日志不回显）；
- **服务端与核心包单测齐备**。

该端点同时服务**文件窗格的纯文本预览**与 **Obsidian tab 的 markdown 预览**——两处预览共用一条只读通道，不另开第二条；**大文件行为也必须一致**（同一对话框、同一进度条、同一「不截断」口径）。

### 七、镜像与环境变量补齐（并入任务 02）

本轮**顺带**做两件事——因为任务 02 本来就要动镜像、bump 版本。

**① base image 补 UTF-8 locale ENV**

- base image 的 Dockerfile **新增** `ENV LANG=C.UTF-8` 与 `ENV LC_ALL=C.UTF-8`（**纯新增**——现状 Dockerfile **一条 ENV 都没有**，容器内 locale 处于**未定义态**）；
- 这与看板 TODO「**终端中文间歇乱码**」的排查方向②「**容器内 locale 非 UTF-8**」直接相关——该项**落地后该 TODO 不自动关闭**，**以实测观察是否收敛为准**。
- 此外，容器创建时平台**强制注入** `LANG` / `LC_ALL` = `C.UTF-8`（**平台值优先**于用户同名 env，与 `SANDBOX_NETWORK` 同口径，覆盖创建与重启两条路径）——镜像 ENV 是基础层，平台注入是强制层，防止用户 env 静默把 locale 打回非 UTF-8。

**② 创建沙箱容器时注入 `SANDBOX_NETWORK`**

- **值 = 实际生效的 docker 网络名**：默认 `<沙箱名>-net`；**用户创建时指定了自定义网络则取用户指定值**——**绝不能字符串拼 `<沙箱名>-net`**；
- **用途**：沙箱内挂载了**自己用户的 rootless docker 套接字**、镜像里有 **docker CLI**，内部 `docker run --network "$SANDBOX_NETWORK"` 即可与**沙箱容器、转发容器同网按名互访**；
- **注入机制**：`SANDBOX_NETWORK` 是**容器内变量**（与既有终端会话 exec 注入的 `SANDBOX_TERMINAL_SESSION` **命名风格一致**），**不是宿主平台参数**（平台参数前缀是 `SANDBOX_PLATFORM_*`）；建议注入在**容器运行的 env 合并处**、**不写入 metadata、不经 API 响应掩码**；
- **创建与重启两条路径都要覆盖**，**核心包单测齐备**。

**ADR 0004 修订范围的扩大**：[[architecture/decisions/0004-镜像契约与默认沙箱镜像.md|ADR 0004]] §3「运行时极简」写有「沙箱启动即一个 bash，不加载任何 profile 脚本；不能靠 shell 初始化脚本注入环境变量与别名」。原任务 08 已计划为 bashrc 的 PS1 注入**追加一条 ADR 修订行**——本轮**修订范围扩大**：**PS1 注入**与 **Dockerfile 新增 ENV 指令**两条都要由该修订行覆盖（修订行由**任务 08** 统一落，历史表述不改写）。
