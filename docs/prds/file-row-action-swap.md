> 日期：2026-11-28
> 用户拍板：文件窗格文件行的交互语义反转；本轮代码已完成，代码未提交、未发布，用户验收待执行。
> 历史来源：[[prds/file-pane-obsidian.md|文件窗格与 Obsidian 阅读器 PRD]]；旧语义仅作历史留档。

## 背景

文件窗格旧约定是「单击文件行下载、hover 眼睛按钮预览」。用户于 2026-11-28 拍板反转两条路径，使文件行的主操作更适合先阅读内容。

## 目标

- 文件行单击进入预览；预览沿用原 hover 眼睛按钮路径，包括大于 2 MB 文件的二次确认。
- 文件行 hover 浮现下载按钮，使用 lucide `Download` 图标，`aria-label="下载"`，约 150ms 淡入、可聚焦，并阻止事件冒泡。
- 目录行保持原有目录导航语义。
- 网页与桌面共用的文件窗格组件两端一致生效。

## 非目标

- 不改变目录行行为、下载通道、预览内容、二次确认和进度条口径。
- 不在本轮重构既有的嵌套交互控件 ARIA 结构；该风险单独登记 TODO。
